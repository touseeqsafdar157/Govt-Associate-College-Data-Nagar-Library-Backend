# Govt Associate College Data Nagar Library - Backend API

Node.js + Express + TypeScript REST API backend for College Library Management System.

## Features
- **Authentication**: JWT authentication with roles (`librarian`, `admin`, `teacher`, `student`).
- **Books Management**: Full CRUD operations for books, search, filtering by department/category.
- **Shelves & Almaris**: Almaris and shelf rack management.
- **Member Registry**: Student and faculty registration, status toggling.
- **Circulation Desk**: Book issuance, return, 7-day renewal, fine calculation and waivers.
- **Reading Room**: 60-desk study hall real-time booking and vacating.
- **Digital Library**: BISE Lahore past papers, solved notes, lecture slides.
- **Announcements & Suggestions & Feedback**: Real-time communication and purchase requests.
- **Dashboard Analytics**: Real-time summary statistics for college administration.

## Installation & Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
